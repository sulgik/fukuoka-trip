# 후쿠오카 가족여행 가이드

가족과 공유할 수 있는 반응형 정적 여행 가이드입니다. PWA 기능 없이 브라우저에서 바로 열리며, GitHub Pages로 배포할 수 있습니다.

## 파일

- `index.html`: 여행 일정, 이동 정보, 체크리스트가 포함된 메인 페이지
- `404.html`: GitHub Pages에서 잘못된 경로로 접근했을 때 메인 페이지로 이동

## 로컬에서 보기

`index.html`을 브라우저에서 열면 됩니다. 로컬 웹 서버를 사용하는 경우 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8000
```

그런 다음 <http://localhost:8000>을 엽니다.

## GitHub Pages

이 저장소는 `main` 브랜치의 루트 디렉터리를 GitHub Pages로 게시하도록 구성합니다.

체크리스트 상태는 각 브라우저의 로컬 저장소에 보관되므로 기기 간에 동기화되지는 않습니다.
